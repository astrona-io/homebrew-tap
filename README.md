# astrona-io/homebrew-tap

Homebrew tap for [astrona](https://github.com/astrona-io/astrona-cli), the Astrona lab CLI.

```sh
brew install astrona-io/tap/astrona
```

Upgrade with `brew upgrade astrona`.

`Formula/astrona.rb` is updated automatically by the astrona-cli release workflow on every tagged release — don't edit it by hand.
